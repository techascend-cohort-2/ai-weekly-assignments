# Week 2 – Grading Criteria (AI Track)

Total: 100 Points

---

# 1. Data Loading (20 points)

- Dataset loaded correctly (10)
- Code runs without errors (10)

---

# 2. Data Exploration (25 points)

- First rows displayed (5)
- Data structure inspected (10)
- Basic statistics calculated (10)

---

# 3. Analysis & Insights (25 points)

- Average values calculated (10)
- Maximum or minimum values identified (5)
- Results clearly explained (10)

---

# 4. Code Quality (10 points)

- Code readable and organized (5)
- Logical structure of analysis (5)

---

# 5. Git Usage (10 points)

- Minimum 3 commits (5)
- Clear commit messages (5)

---

# 6. README Reflection (10 points)

- Dataset explained (5)
- Insights and challenges documented (5)

---

# Automatic Deductions

Points may be deducted for:

- Code that does not run
- Missing dataset
- Missing README
- Single commit repository
- Late submission

---

# Key Evaluation Principle

The goal of this assignment is to demonstrate:

- Ability to load and explore data
- Basic analytical thinking
- Clear explanation of results
