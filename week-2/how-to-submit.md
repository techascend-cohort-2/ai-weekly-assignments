# Week 2 – Submission Guide (AI Track)

Follow these instructions carefully when submitting your Week 2 assignment.

---

# Step 1 – Create Your Repository

Create a public GitHub repository using this naming format:

techascend-week2-ai-FirstnameLastname

Example:

techascend-week2-ai-AmaraNdi

---

# Step 2 – Required Files

Your repository must contain:

- week2.py OR week2.ipynb
- dataset.csv
- README.md

Example structure:

project-folder/
  week2.ipynb
  dataset.csv
  README.md

---

# Step 3 – Required README Format

Your README.md must include:

TechAscend Cohort 2 – Week 2

Name:
Track:
Slack Username:

## Dataset Used
Explain what dataset you used.

## Analysis Performed
Describe the calculations you performed.

## Key Insights
What interesting results did you discover?

## Challenges Faced
What problem did you encounter and how did you solve it?

---

# Step 4 – Git Requirements

Your repository must include:

- Minimum **3 commits**
- Clear commit messages

Example:

- Added dataset
- Implemented data analysis
- Improved output formatting

---

# Step 5 – Slack Submission

Submit your assignment in the AI track channel using this format:

WEEK 2 SUBMISSION

Name:
GitHub Repo Link:
Number of Commits:

Example:

WEEK 2 SUBMISSION

Name: Amara Ndi  
GitHub Repo: https://github.com/amara/techascend-week2-ai-AmaraNdi  
Commits: 3

---

# Deadline

Sunday – 11:59 PM

Late submissions may not receive full evaluation.

---

# Important

Assignments must be submitted via GitHub.

Do not submit through:

- Direct messages
- Google Drive
- File uploads
