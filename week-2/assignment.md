# Week 2 – AI Track
## Data Analysis with Python

Week 2 introduces basic data analysis using Python.

You will load a dataset and extract simple insights.

---

## Objective

Learn how to:

- Load data from a CSV file
- Inspect data
- Perform simple calculations
- Display results

---

## Assignment

Create a Python script or Jupyter Notebook that:

1. Loads a dataset
2. Displays the first few rows
3. Calculates simple statistics
4. Prints useful insights

---

## Dataset

You may use any small dataset.

Examples:
- Student scores
- Product sales
- Weather data

Example dataset format:

Name,Score
Alice,85
John,90
Maria,78

---

## Required Tasks

Your code must:

1. Load the dataset
2. Print the first 5 rows
3. Calculate the average value of a column
4. Find the maximum value
5. Print a short summary of results

Example output:
Average Score: 84.3
Highest Score: 95


---

## Libraries

You may use:

- Python standard library
OR
- pandas
